# G5 (3단계): 강화 기댓값 Implementation Plan

> 자동 반복 모드(goal 설정 C). 성공 기준: `GOALS.md` G5. 스펙 §6.

## 데이터 (2026-10-03 조사, 원문 수치 그대로)

- 스타포스 확률: 공식 기본 확률(0~14성: 2024-05 공식 검증표, 15~29성: 2025-03-20 패치노트 Update/767) × 스타캐치 상시 적용(2026-03-19 Update/799 "스타캐치 성공 시 상승하던 성공 확률은 항상 적용"). 현재 값 = 성공 ×1.05, 유지·파괴는 비례 축소. 나무위키 현재표와 일치. 공식 사후표 미발견 → `verified: false`.
- 실패 시 단계 유지(하락 없음), 파괴 시 흔적 = 파괴 직전 성(23성 이상에서 파괴되면 22성). 완전 복구(같은 성으로) 또는 기본 복구(12성).
- 파괴 방지: 15·16·17성 시도에만, 기본 메소 +200%, 할인 미적용.
- 비용: `1000 + L³(S+1)/36` (0~9성), `1000 + L³(S+1)^2.7/D` (10성~), 십의 자리 반올림 — 나무위키, 비공식.
- 이벤트: 30% 할인(×0.7, 파괴 방지 추가금 제외), 21성 이하 파괴 확률 ×0.7, 5·10·15성 100% 성공.
- 큐브(잠재능력 재설정 = 블랙 큐브): 공식 확률 페이지 Guide/OtherProbability/cube/black. 줄별 현재 등급 확률 1줄 100%·2줄 20%·3줄 5%, 등급 상승 확률·천장(15%/10, 3.5%/42, 1.4%/107), 레전드리·무기·200레벨 옵션표. 메소 가격표는 나무위키(비공식).

## Rulings
- Ruling: 파괴 확률 30% 감소 이벤트에서 줄어든 파괴 확률은 "유지"로 간다 — 확인 불가(조사 UNVERIFIED), 성공 확률을 바꾸지 않는 해석이 보수적 — 틀리면 이벤트 기댓값이 약간 낙관/비관.
- Ruling: 파괴 처리 비용은 사용자 입력(`destroy_cost`, 스페어 시세+복구 메소)으로 받는다. 복구 메소는 공식 공식이 없다 — 스펙 §6 "사용자가 넣는 값".
- Ruling: 큐브 "직전 결과와 완전히 같은 3줄은 나오지 않음"과 중복 제한(쓸만한 스킬 등)은 딜 옵션 판정에 영향이 무시할 만하고 대상 옵션이 제한 목록에 없어 모델에서 뺀다.
- Ruling: 큐브 1회 결과의 줄은 서로 독립(각 줄 표에서 따로 추첨).

# G4 (2단계): React+Vite 웹 Implementation Plan

> 자동 반복 모드(goal 설정 C). 성공 기준: `GOALS.md` G4. 스펙 §3(web), §7.

## Rulings
- Ruling: TypeScript 대신 JSX — 화면이 작고(조회·세팅표·매물폼·결과표) 계산은 서버가 한다. 타입 이득보다 설정 비용이 크다 — 틀리면 나중에 TS 전환 비용.
- Ruling: 가격 입력은 "45억 3000만"·"4.5억"·숫자(메소)를 모두 받는다(`parsePrice`). 경매장 표기를 그대로 옮기기 위해.
- Ruling: 매물 목록은 브라우저 localStorage에 저장(스펙 §7), 접근 실패는 무시하고 메모리로 동작.
- Ruling: FastAPI가 `web/dist`를 `/`에 서빙(API 라우트 뒤에 마운트). 개발 중에는 Vite proxy로 `/api` → `127.0.0.1:8000`.

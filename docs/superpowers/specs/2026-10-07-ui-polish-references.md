## 적용 원칙
- **숫자**: 모두 `tabular-nums`. KPI는 `--fs-2xl` 굵게, 라벨은 `--fs-xs` 흐린 글자. 숫자를 만들지 않는다 — 서버가 준 값만.
- **위계**: 페이지 제목(`--fs-xl`) → 카드 제목(`--fs-md`) + 한 줄 설명(`--fs-sm` 흐림) → 본문. 카드 안 여백 `--sp-5`(20px), 카드 사이 `--sp-4`.
- **아이콘**: 직접 그린 24px 선 아이콘(2px, `currentColor`) — 탭·메뉴·빈 상태·오류에만. 장식용은 `aria-hidden`.
- **사용 방법**: 각 패널 머리말 아래 한 줄 "할 수 있는 것" + 접히는 `사용 방법`(번호 2–4단계). 첫 화면엔 처음 온 사람용 3단계 안내(닫으면 이 브라우저에서 다시 안 뜸).
- **상태**: 로딩=내용 모양 뼈대, 빈=설명 + 다음 행동, 오류=빨간 선 카드 + 다시 시도. 빈 화면을 두지 않는다.
- **접근성**: `:focus-visible` 고리, 버튼 최소 높이 36px(휴대폰 40px), `prefers-reduced-motion`이면 애니메이션 끔.
- **다크**: 바탕·면·면2 세 단계로 깊이를 주고 그림자 대신 선을 밝힌다. 강조색 위 글자는 대비 4.5:1 이상.

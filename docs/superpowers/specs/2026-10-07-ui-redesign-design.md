# UI 개편 설계 (2026-10-07)

## 목적과 결정 (사용자)
- 주 사용자: **일반 유저**. 흐름은 닉네임 검색 → 내 스펙 요약 → 무엇을 바꾸면 좋은지(업그레이드).
  화면 분석·채점·AI 상담·매물 직접 입력은 관리자 화면으로 분리한다.
- 테마: **라이트·다크 둘 다**, 전환 버튼, 기본은 시스템 설정.
- 기기: **PC·휴대폰 모두 어색하지 않게** — 배치를 따로 만들어도 된다.
- 구현 방식: **A — 지금의 React + 직접 쓴 CSS(디자인 토큰)**. 새 UI 의존성 없음.
- 장비창 훑기 개선은 이번 범위 밖(나중).

## 레퍼런스에서 가져온 것 (조사 2026-10-07)
maple.gg(요약 카드·갱신 시각), 넥슨 랭킹(메달 순위 표), MapleScouter(테마 전환·공유 URL), 츄츄지지(`/` 검색 단축키),
메애기(카드 그리드·월드 배지), devcomma 스타포스(입력/결과 나란히·숫자 카드), op.gg(가운데 큰 검색창).
피할 것: 기능 수십 개 메뉴, 로딩 중 빈 화면, 설명 없는 아이콘 토글.

## 1부 — 화면 구조와 데이터

### 주소(해시 라우팅 — Render에서 서버 설정 없이 동작)
| 주소 | 화면 |
|---|---|
| `#/` | 첫 화면: 가운데 큰 검색창, 최근 검색(이 브라우저 localStorage), 계산기 바로가기 |
| `#/c/<닉네임>?tab=summary\|upgrade\|calc` | 캐릭터: 요약 카드 + 탭 3개. 탭은 주소에 남는다(새로고침·공유 유지) |
| `#/calc` | 계산기만(캐릭터 없이) |
| `#/admin` | 관리자: 로그인·화면 분석·채점·AI 상담·매물 직접 입력. 메뉴에 노출하지 않는다 |
알 수 없는 주소는 `#/`로.

### 컴포넌트(`web/src/`)
- `router.js` — 해시 주소 ↔ `{page, name, tab}` 변환, `navigate()`, `useRoute()`
- `theme.js` — `light|dark|system` 저장(localStorage)·적용(`<html data-theme>`)
- `layout/TopBar.jsx` — 로고(`#/`), 작은 검색창(첫 화면 제외), 테마 전환
- `layout/BottomTabs.jsx` — 휴대폰(≤720px) 캐릭터 화면 아래 탭 막대
- `pages/Home.jsx`, `pages/Character.jsx`, `pages/Calc.jsx`, `pages/Admin.jsx`
- `character/ProfileCard.jsx` — 아바타·닉네임·월드·길드·직업·레벨, 큰 숫자(전투력·스탯공격력), "기준 시각", [정보 갱신]
- `character/EquipmentGrid.jsx` — 장비창 배치(PC) / 부위 목록(휴대폰), 칸 = 아이콘 + 성 수 배지 + 잠재 등급 테두리,
  누르면 상세(잠재·에디 줄). 프리셋 1·2·3 전환
- `character/SettingsRanking.jsx` — 보스 세팅 순위(1~3위 메달)
- 업그레이드 탭: 기존 `RoadmapPanel`·`PathsPanel`·`RecommendPanel`을 한 탭에 순서대로(가격 대비 순위 → 경로 비교 → 검색 조건)
- 계산기 탭/페이지: 기존 `StarforcePanel`·`CubePanel`·`CraftPanel`, `OptimizePanel`·매물 직접 입력은 관리자로
- `api.js`·`format.js`·계산 로직은 그대로

### 서버에 추가할 데이터(이미 받는 넥슨 응답에서만, 새 호출 없음)
- `GET /api/character/{name}` 응답에 `profile`: `{name, world, guild, image, class_level, date_create}` — 없으면 `null`
- `equipment_presets[n][i]`에 `icon, potential_grade, additional_grade, potentials, additional, level, special_ring_level`
- 캐릭터 이미지·아이콘은 넥슨 Open API가 주는 주소를 그대로 `<img>`로 쓴다(저장·재배포 안 함)

## 2부 — 화면 모양

### 디자인 토큰(`styles.css` `:root` / `[data-theme=dark]`)
- 라이트: 바탕 `#f4f5f8`, 면 `#ffffff`, 선 `#e2e5ec`, 글자 `#1b1f2a`, 흐린 글자 `#667085`, 강조 `#3b5bdb`
- 다크: 바탕 `#0e121b`, 면 `#161c28`, 선 `#263043`, 글자 `#e7eaf1`, 흐린 글자 `#8d96aa`, 강조 `#6c8cff`
- 공통: 금색 포인트 `#f2b84b`(1위·스타포스 별), 오류 `#e5484d`, 반경 10px, 그림자 1단계, 숫자는 `font-variant-numeric: tabular-nums`
- 잠재 등급색: 레어 `#4aa8ff`, 에픽 `#a06bff`, 유니크 `#f5c542`, 레전드리 `#5fd35f`
  - Ruling: 공식 hex를 찾지 못해(조사 결과) 인게임 계열색으로 정한 임시 토큰 — 틀리면 토큰 값만 바꾸면 된다

### 장비창 배치(PC, 5열 — 인게임처럼 좌 2열·가운데 캐릭터·우 2열)
| 왼쪽1 | 왼쪽2 | 가운데 | 오른쪽1 | 오른쪽2 |
|---|---|---|---|---|
| 반지1 | 얼굴장식 | 캐릭터 이미지(4칸 높이) | 모자 | 엠블렘 |
| 반지2 | 눈장식 | 〃 | 망토 | 어깨장식 |
| 반지3 | 귀고리 | 〃 | 상의 | 기계 심장 |
| 반지4 | 펜던트 | 〃 | 하의 | 훈장 |
| 포켓 아이템 | 펜던트2 | 무기 | 장갑 | 뱃지 |
| 예비 특수 반지 | 벨트 | 보조무기 | 신발 | — |
- Ruling: 인게임 장비창의 정확한 칸 위치는 확인하지 못해 "좌 액세서리·우 방어구" 구성으로 정했다. 없는 슬롯은 빈 칸
- 휴대폰: 같은 데이터를 "무기·방어구·장신구·기타" 묶음 목록으로(아이콘·이름·성·등급 색 점)

### 업그레이드 탭
- 맨 위 "가격 대비 순위" 표: 순위(1~3 메달) · 부위 · 현재 → 목표 · 비용 · 실딜 · **억당 효율 막대**(최댓값 대비 폭)
- 그다음 경로 비교, 검색 조건 카드(칩 + [복사])
- 데이터·계산은 기존 API 그대로. 화면 표현만 바뀐다

### 휴대폰(≤720px)
- 위쪽 막대는 로고·검색 아이콘·테마 전환만. 캐릭터 화면은 아래 탭 막대(요약·업그레이드·계산기)
- 카드는 한 줄로, 표는 가로 스크롤 대신 카드 목록으로, 계산기는 입력 위·결과 아래

### 로딩·오류
- 조회 중에는 뼈대 화면(회색 막대) — 빈 화면을 두지 않는다
- 오류는 카드 안에 메시지 + [다시 시도]. 서버가 준 문구 그대로

## 테스트
- 서버: `profile`·장비 필드가 실제 넥슨 데이터 모양(픽스처)에서 채워지고, 없으면 `null`/빈 값
- 웹: 주소 → 화면(4종), 탭 전환이 주소를 바꾼다, 검색 → `#/c/<닉네임>`, 최근 검색 저장, 테마 전환·저장,
  장비창 등급색·성 수·빈 칸, 프리셋 전환, 업그레이드 표 막대 폭, 관리자 화면에서만 화면 분석·AI 상담
- 기존 기능 테스트(패널·화면 분석·에이전트)는 위치만 옮기고 유지
